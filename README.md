# 🧠 Medical Conditions Dashboard using Python & Plotly

This project showcases a **dynamic, interactive medical data dashboard** using Python, Plotly, and Pandas. It provides analytical visualizations for various medical conditions, enabling better insight into demographic and clinical data.

---

## 🔍 Objective

To present patient data grouped by medical conditions in a visually appealing and interactive way, allowing users to explore relationships between age, duration, gender, blood type, hospitals, and more.

---

## 📊 Visualized Features

For each of the following conditions:

- Arthritis
- Diabetes
- Hypertension
- Obesity
- Cancer
- Asthma

A dashboard is generated showing the following charts:

| Visualization Title              | Description                                           |
|----------------------------------|-------------------------------------------------------|
| 📈 Age Distribution              | Histogram with average age annotation                |
| 🧬 Gender Distribution           | Sunburst chart showing gender breakdown              |
| 🩸 Blood Type Distribution       | Line plot of blood type frequencies                  |
| 📆 Duration of Condition         | Histogram with average duration                      |
| 🏥 Top 10 Hospitals              | Horizontal bar chart by billing amount               |
| 🔬 Test Results Distribution     | Sunburst chart showing result counts                 |
| 💊 Medication Distribution       | Bar chart with color scale based on frequency        |
| 🛌 Admission Type Distribution   | Sunburst chart for admission types                   |

Each dashboard is structured in a 3x3 grid using `plotly.subplots`.

---

## 🛠️ Tech Stack

- **Python 3.9+**
- **Pandas** for data manipulation
- **Plotly Express** and **Plotly Graph Objects** for visualizations
- **Jupyter / Kaggle Notebook** for execution

---

## 🚀 Getting Started

1. Load the dataset (structured with columns like `Medical Condition`, `Age`, `Gender`, `Duration`, etc.)
2. Run the notebook from top to bottom.
3. Visual dashboards will render for each medical condition.
